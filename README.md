- `resource-covers/` — Cover images (1200x800) for each VibeFlow resource (RES-XXX). Used as clickable previews on the public Notion hub page.

## Why this repo

The ContentFlow Lab production repo is private. This repo only hosts public assets that need a stable URL (raw.githubusercontent.com) for embedding in Notion pages, social bios, etc.
